# ICDFA GRC103 - Risk Monitoring Dashboard and Management Reporting (Module 4, Lab 2)

## Overview
This repository contains the submission for the ICDFA GRC103 Module 4 practical lab, "Risk Monitoring Dashboard and Management Reporting." The exercise uses a fictional three-month dataset for Northbridge Services to calculate and classify five monitoring indicators, interpret the results, update a risk register, build an action and assurance plan, and write a one-page management report.

## Workbook
The editable spreadsheet contains the source data, live formulas for all five indicators (monitoring coverage, timely critical-alert review, restore-test success, confirmed unauthorised changes, overdue high-risk action rate), RAG threshold classification against unrounded values, and the required trend charts (percentage indicators trended separately from the unauthorised-changes count).

## Report (3 pages)
1. **Management report** - March status, three priority concerns with figures cited and observation kept separate from possible cause, decisions and resources requested, owners and next review.
2. **Risk register** - four entries, each with an individually justified likelihood and impact rating (not auto-derived from the RAG colour).
3. **Action and assurance plan** - a short-term containment action and a longer-term improvement per risk, each with an owner, target date, and an outcome-based verification test. No action is marked complete.

All figures in this submission are fictional classroom data.
